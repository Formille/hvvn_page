# 브랜드 이미지 안내

아래 파일명으로 이 폴더(`public/images/`)에 넣어주세요. 파일이 없으면
사이트는 자동으로 고딕 텍스트 로고("hvving")로 폴백됩니다.

| 파일명 | 어떤 이미지 | 쓰이는 곳 |
| --- | --- | --- |
| `hvving-chrome.png` | 은색 크롬 가로 워드마크 (4번 이미지) | 헤더 + 메인 상단 대형 로고 |
| `hvving-vertical.png` | 세로 고딕 가시체 로고 (3번 이미지) | 메인 좌측 세로 컬럼 (데스크탑) |
| `hvving-bw.png` | 흑백 포스터화 워드마크 (5번 이미지) | 푸터 |
| `hvving-chrome-blue.png` | 파란 크롬 워드마크 (2번 이미지) | (선택) 추후 히어로/배너 교체용 |

- 배경(파란 벨벳)은 CSS로 구현되어 있어 별도 이미지가 필요 없습니다.
  실제 벨벳 사진을 쓰고 싶으면 알려주세요. `body` 배경에 오버레이로 넣어드릴게요.
- PNG는 가능하면 **투명 배경**으로 저장하면 벨벳 위에 자연스럽게 얹힙니다.
